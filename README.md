# Tarang

AI-Powered audio platform — text-to-speech, voice cloning, and audio separation.

---

### What it does

- **Text-to-Speech** — Generate natural speech from text
- **Voice Cloning** — Clone any voice from a short audio sample
- **Audio Separation** — Isolate vocals, drums, bass, and instruments
- **Voice Library** — Browse preset voices or save custom profiles

---

### Built with

FastAPI · Next.js · PostgreSQL · Modal · Cloudflare · Clerk
